The onboarding pre-permission button now says "Continue" instead of "Allow". The explanatory copy describes why location is useful before the system permission prompt appears.

## Guideline 2.5.4

Squad Brunch uses persistent background location only for the live ETA feature during an active meetup. The feature is user-initiated from the meetup dashboard:

1. Sign in on two physical devices.
2. Create a meetup on device A and invite device B.
3. Join the meetup on device B and RSVP "Yes".
4. Open the active meetup dashboard on device B.
5. Tap "Start Sharing Location".
6. Background device B and keep the dashboard open on device A.
7. Confirm device A continues to show device B's live ETA/location updates.
8. Return to device B and tap "Stop Sharing Location".
9. Confirm device A no longer shows device B's live location.

Attach a screen recording of these steps to App Review Notes for future submissions. Mention that live ETA sharing continues in the background only until the user stops sharing or the meetup expires.
